# 🧠 Agentes de Inteligência Artificial

Este repositório foi criado para o **Curso de Agentes de Inteligência Artificial**, promovido pelo **Instituto I2A2** com o patrocínio da **META**.

Aqui serão armazenadas todas as atividades, projetos, experimentos e códigos desenvolvidos ao longo do curso.

---

## 🚀 Sobre o Curso

O curso tem como objetivo capacitar os participantes na construção e desenvolvimento de agentes de inteligência artificial, abordando desde os conceitos básicos até aplicações práticas, utilizando ferramentas e frameworks modernos.
